# 🌍 WorldCup Fantasy Agent (WCA)

**Submission for Google Cloud Rapid Agent Hackathon 2026**

An autonomous AI Agent for managing 2026 FIFA World Cup Fantasy Leagues with persistent data via MongoDB MCP.

## Features
- Real 2026 World Cup match data (104+ fixtures seeded)
- Create & track fantasy leagues
- Make & save predictions
- Social sharing ready
- Multi-step agentic capabilities (planning + execution)

## Tech Stack
- **MongoDB Atlas** + **MCP Toolbox** (core persistence superpower)
- **Streamlit** frontend
- Ready for **Gemini / Google Cloud Agent Builder**
- TheSportsDB / openfootball data
